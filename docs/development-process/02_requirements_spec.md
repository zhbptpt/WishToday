## 范围

本阶段将已签收的 v0.2.0 产品简报转换为可测试的功能需求、非功能需求、权限规则、数据要求、边界场景和验收标准。不选择认证服务、数据库、API 框架或部署平台，不设计视觉页面，不实现代码。

## 已完成工作

- 将“真实账户与云端私人笔记本”拆分为账户、会话、云端保存、跨设备读取、本地导入和失败恢复六类 P0 需求。
- 定义游客、未验证账户和已验证登录用户的权限边界。
- 确认多设备会话、密码重置后的会话失效和认证回跳行为。
- 确认本地主动导入、按来源标识判重、部分失败重试和默认保留本地记录。
- 定义安全、隐私、可靠性、性能、可访问性和兼容性要求。
- 建立发布验收矩阵与 v0.1.0 核心链路回归门槛。

## 决策

- 采用一次交付的最小云端闭环，全部核心能力列为 P0。
- 未验证邮箱的账户只有游客能力，不能读取或写入云端私人数据。
- 同一账户允许多设备同时登录；密码重置成功后使全部旧会话失效。
- 本地配方只能在用户明确操作后上传，并以“账户 + 本地记录 ID”判重。
- 云端写入和重试必须幂等；失败不丢草稿、不伪装为空状态。
- 私人配方默认私有，不用于营销、画像或公开展示。

## 角色与权限

| 角色/状态 | 游客核心链路 | 云端保存 | 私人笔记本与详情 | 本地导入 | 账户操作 |
| --- | --- | --- | --- | --- | --- |
| 游客 | 允许 | 触发登录或注册 | 拒绝并引导登录 | 不允许 | 注册、登录、忘记密码 |
| 未验证邮箱账户 | 允许 | 不允许 | 不允许 | 不允许 | 重发验证邮件、登录、退出 |
| 已验证登录用户 | 允许 | 允许 | 仅访问本人数据 | 允许主动触发 | 退出、会话恢复、忘记/重置密码 |

## 用户故事

- US-01：作为游客，我希望无需登录即可探索推荐、调整配方并预览，确认产品价值后再决定是否注册。
- US-02：作为新用户，我希望用邮箱注册并完成验证，以安全建立自己的私人笔记本。
- US-03：作为已验证用户，我希望登录状态能在正常刷新后恢复，并可在多台设备同时使用。
- US-04：作为忘记密码的用户，我希望安全重置密码，并让旧设备上的会话失效。
- US-05：作为调酒爱好者，我希望将预览配方保存到云端，在其他设备查看同一份记录。
- US-06：作为 v0.1.0 用户，我希望自主决定是否将本地配方导入账户，且重复操作不会制造重复记录。
- US-07：作为遇到网络故障的用户，我希望草稿仍在，并能从明确入口恢复保存或加载。

## P0 功能需求与验收标准

### AUTH-01 邮箱注册

系统必须支持邮箱和密码注册。邮箱忽略首尾空格并按不区分大小写识别同一地址；密码至少 8 个字符，允许粘贴和密码管理器填充，不强制字符组合。

- Given 邮箱有效且未被占用、密码符合基线，When 提交注册，Then 创建待验证账户并发送验证邮件。
- Given 邮箱无效或密码少于 8 个字符，When 提交，Then 阻止请求并显示字段级错误。
- Given 邮箱已存在，When 提交，Then 使用不泄露账户状态的通用提示，并提供登录或找回密码入口。
- Given 注册正在提交，When 再次触发，Then 不产生重复账户或并发重复请求。

### AUTH-02 邮箱验证

新账户必须验证邮箱后才能访问云端私人数据。验证链接必须一次性且有有效期。

- Given 用户打开有效链接，When 验证成功，Then 账户变为已验证并可返回应用登录。
- Given 链接无效、过期或已使用，When 打开，Then 不验证账户，并提供重新发送入口。
- Given 账户未验证，When 请求云端保存、笔记本、详情或导入，Then 拒绝并提示先验证。
- Given 用户重发验证邮件，When 请求被接受，Then 使用通用成功提示，并限制滥用频率。

### AUTH-03 登录、退出与会话

系统必须支持已验证账户登录、显式退出和刷新后的会话恢复；同一账户允许多设备同时登录。

- Given 凭据正确且邮箱已验证，When 登录，Then 建立会话并执行来源对应的后续动作。
- Given 凭据错误、邮箱不存在或账户不可登录，When 登录，Then 显示通用失败信息，不泄露邮箱是否存在。
- Given 邮箱未验证，When 提交正确凭据，Then 不授予云端权限，并提供重发入口。
- Given 会话有效，When 刷新或重新打开应用，Then 恢复已登录状态。
- Given 用户退出，When 完成，Then 当前设备会话失效，其他设备会话不受影响。
- Given 会话过期，When 执行受保护操作，Then 保留草稿并要求重新登录，成功后继续原动作。

### AUTH-04 忘记密码与重置

系统必须支持邮箱密码重置。申请提示不得泄露邮箱是否存在；重置链接必须一次性且有有效期。

- Given 用户提交任意格式有效邮箱，When 请求重置，Then 显示相同的通用完成提示。
- Given 有效链接和符合基线的新密码，When 重置成功，Then 全部旧会话失效，用户需重新登录。
- Given 链接无效、过期或已使用，When 提交，Then 不修改密码并提供重新申请入口。
- Given 密码已重置，When 使用旧密码登录，Then 登录失败且不泄露额外信息。

### FLOW-01 游客链路与认证回跳

游客必须继续完成 `今日推荐 -> 详情 -> 实验台 -> 预览`；只有云端保存或访问私人笔记本要求登录。

- Given 用户未登录，When 进入详情、实验台和预览，Then 不强制登录且草稿持续存在。
- Given 游客从预览触发保存，When 完成验证和登录，Then 自动继续保存原草稿，成功后打开新配方详情。
- Given 游客访问笔记本，When 完成登录，Then 返回笔记本，而非固定跳转首页。
- Given 认证取消、失败或会话过期，When 返回预览，Then 原草稿仍可编辑或再次保存。

### RECIPE-01 云端保存与幂等

已验证用户可将当前预览配方保存到自己的云端私人笔记本，记录默认私有。

- Given 用户拥有有效草稿，When 保存成功，Then 生成一条归属当前账户的私人配方并返回详情。
- Given 同一保存因重复点击、网络重试或认证回跳重复提交，When 处理，Then 最多生成一条配方。
- Given 保存进行中，When 再次点击，Then 客户端不发起并发重复写入。
- Given 保存失败或超过 10 秒，When 返回错误，Then 保留草稿并提供“重试保存”。
- Given 其他账户知道配方 ID，When 请求，Then 拒绝访问且不返回配方内容。

### RECIPE-02 笔记本与跨设备读取

已验证用户可查看自己的云端配方列表和只读详情。列表按最近保存时间倒序，跨设备以云端数据为准。

- Given 设备 A 已保存配方，When 设备 B 登录同一账户，Then 可在笔记本查看并打开详情。
- Given 存在多条配方，When 打开笔记本，Then 按保存时间倒序展示。
- Given 没有云端配方且加载成功，When 打开，Then 显示真实空状态。
- Given 列表或详情加载失败，When 打开，Then 显示错误和“重新加载”，不得显示为空状态。
- Given 详情加载成功，When 查看，Then 页面只读，不提供编辑、删除、收藏或发布。

### IMPORT-01 本地配方检测与主动选择

已验证用户登录后，如当前浏览器存在 v0.1.0 本地已保存配方，系统必须显示待导入数量，让用户选择“立即导入”或“稍后处理”，不得静默上传。

- Given 存在本地配方，When 首次以已验证账户登录，Then 显示待处理数量和数据用途说明。
- Given 用户选择稍后处理，When 关闭提示，Then 不上传、不修改、不删除，并在后续合适时机再次提供入口。
- Given 用户未点击导入，When 观察网络请求，Then 不得出现包含本地配方正文的上传。
- Given 没有本地配方，When 登录，Then 不显示空的导入提示。

### IMPORT-02 判重、结果与重试

导入以“当前账户 + 本地记录 ID”为来源唯一性规则。内容相似但本地记录 ID 不同的配方不自动合并。

- Given 本地记录从未导入当前账户，When 成功导入，Then 创建携带来源标识的云端配方。
- Given 当前账户再次导入相同本地记录 ID，When 处理，Then 跳过且不生成重复项。
- Given 不同账户导入相同本地记录 ID，When 处理，Then 可各自拥有一条私人配方。
- Given 两条内容相同但本地记录 ID 不同，When 导入，Then 不按内容自动合并。
- Given 批量导入部分失败，When 结束，Then 分别显示成功、已跳过、失败数量，成功项不回滚。
- Given 用户重试失败项，When 请求重复到达，Then 只处理未成功记录并保持幂等。
- Given 导入完成，When 流程结束，Then 默认保留本地记录，不自动删除。

### ERROR-01 通用失败恢复

账户、保存、读取和导入请求必须提供加载、成功、失败或超时状态，并有明确恢复路径。

- Given 请求已发出，When 200ms 内未完成，Then 显示处理中反馈并阻止重复提交。
- Given 请求超过 10 秒，When 超时，Then 用户可取消或重试，不无限加载。
- Given 原请求已成功但响应丢失，When 用户重试，Then 幂等规则避免重复账户、配方或导入项。
- Given 会话在操作中失效，When 重新登录，Then 恢复原目标动作且不丢草稿。

## P1 需求

- P1-01：重发验证邮件显示可访问的倒计时和下一次可用时间。
- P1-02：导入结果可展开查看每条失败记录的简短原因；只重试失败项仍属于 P0。
- P1-03：在再次导入入口上持续显示待处理数量，减少用户重新判断成本；再次发起导入的入口本身仍属于 P0。

P1 可延期，但不得移除 P0 中的重发入口、结果计数、失败重试或再次导入能力。

## P2 与明确非目标

v0.2.0 不包含：社区/酒鬼圈、发布、收藏、摇一摇、个人资料管理、手机号登录、第三方登录、从零创建配方、编辑或删除已保存配方、笔记本搜索或筛选、账户注销、数据导出、营销订阅、用户画像、公开配方，以及经典鸡尾酒配方库。

经典鸡尾酒配方库保留为 v0.3.0 候选方向，不得回流到本规格。

## 数据需求

### 账户与会话

- 账户稳定标识、规范化邮箱、邮箱验证状态、创建和更新时间。
- 密码仅由认证系统以安全摘要或托管凭据处理，应用数据、日志和浏览器持久化不得保存明文密码。
- 会话关联账户和有效状态，支持单设备退出和密码重置后的全局失效。
- 验证与重置令牌必须一次性、有有效期，不得写入普通应用日志。
- 浏览器不得将密码或可长期冒用的敏感令牌写入当前 Zustand 持久化对象。

### 云端配方

- 配方稳定标识和拥有者账户标识。
- v0.1.0 已保存配方的完整只读内容，包括名称、来源、材料、用量、步骤、风味标签和必要时间字段。
- 创建/保存时间和更新时间，用于稳定排序与审计。
- 通过本地导入创建的配方必须保存本地来源标识，用于当前账户内的导入幂等与判重；直接云端保存的配方不要求该字段。
- 每条云端配方恰好归属一个账户，默认私有。
- 跨设备以云端成功保存的数据为准；未上传草稿和本地记录不自动同步。

### 本地数据生命周期

- 选择稍后处理、导入失败或导入成功均不自动删除本地记录。
- v0.2.0 不提供账户注销或数据导出，但隐私说明必须如实说明当前支持范围。

## 非功能需求

### 安全与隐私

- 生产环境账户与私人配方传输必须使用 HTTPS。
- 所有私人数据请求必须执行服务端账户归属校验。
- 密码、验证令牌和重置令牌不得出现在分析事件、错误日志、URL 查询参数或配方数据中。
- 登录、注册和找回密码反馈不得泄露邮箱是否已注册。
- 注册、登录、验证邮件和密码重置请求必须具备服务端滥用限制；阈值由技术设计确定。
- 邮箱仅用于账户验证、登录、安全通知和密码恢复，不用于营销订阅。
- 私人配方不用于用户画像或公开展示；本地配方仅在用户明确点击后上传。
- 日志不得记录完整私人配方正文；诊断仅使用记录 ID、错误码和脱敏账户标识。

### 可靠性与性能

- 注册、保存、认证回跳、导入和失败重试必须幂等。
- 刷新、认证跳转、会话过期和网络失败不得导致草稿静默丢失。
- 加载失败、无权限和真实空状态必须可区分。
- 网络操作 200ms 内出现处理中反馈；正常网络下目标响应时间为 3 秒内；超过 10 秒进入可恢复超时状态。
- 具体分页、缓存和批处理策略由技术设计确定。

### 可访问性与兼容性

- 账户表单、导入提示和错误恢复可仅用键盘完成。
- 输入项有程序可读标签；错误与成功反馈可被辅助技术感知，且不只依赖颜色。
- 认证跳转或弹层关闭后，焦点回到标题、错误摘要或原触发控件。
- 支持当前及前一个主要版本的 Chrome、Edge、Firefox、Safari，以及常见手机宽度。
- 本地存储不可用时云端账户、保存和笔记本仍可使用，同时明确提示草稿无法跨刷新本地恢复。

## 错误与边界场景

| 场景 | 预期行为 |
| --- | --- |
| 邮箱大小写或首尾空格不同 | 规范化后按同一邮箱识别 |
| 验证/重置链接过期或重复使用 | 不改变账户，提供重新申请入口 |
| 未验证账户请求私人数据 | 拒绝并引导验证，不返回数据 |
| 未知邮箱登录或找回密码 | 使用通用提示，不泄露账户存在性 |
| 多设备同时登录 | 均可使用，单设备退出不影响其他设备 |
| 密码重置 | 全部旧会话失效，新密码重新登录 |
| 保存响应丢失后重试 | 最多一条配方 |
| 列表请求失败 | 错误状态，不显示为没有配方 |
| 其他账户请求配方 ID | 拒绝且不返回正文 |
| 用户选择稍后导入 | 不上传、不删除，后续仍有入口 |
| 同一来源重复导入 | 计为跳过，不新建记录 |
| 导入部分失败 | 成功项保留，失败项可单独重试 |
| 本地存储不可用 | 云端功能可用，提示草稿恢复限制 |
| 网络在认证或保存中断开 | 保留草稿并提供重新登录或重试 |

## 发布验收矩阵

| 验收领域 | 必须覆盖的 P0 场景 |
| --- | --- |
| 注册与验证 | 注册、输入校验、重复提交、有效/过期验证、重发、未验证拒绝 |
| 登录与会话 | 成功/失败、会话恢复、多设备、单设备退出、过期恢复 |
| 密码恢复 | 通用提示、有效/过期链接、新密码、旧会话失效 |
| 权限 | 游客路径、未验证拒绝、本人读取、跨账户越权拒绝 |
| 保存 | 已登录保存、认证后继续、重复点击、响应丢失、失败保留草稿 |
| 跨设备 | 设备 A 保存、设备 B 查看、列表倒序、详情只读 |
| 本地导入 | 待导入数量、主动同意、稍后处理、无静默上传、判重、账户隔离 |
| 导入恢复 | 结果计数、部分失败、不回滚、只重试失败项、重试幂等 |
| 页面状态 | 加载、空、失败、超时、无权限状态可区分且可恢复 |
