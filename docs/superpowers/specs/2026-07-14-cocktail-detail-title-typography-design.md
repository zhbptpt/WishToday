# CocktailDetailPage 标题字设计规范

日期：2026-07-14  
修订：2026-07-15 主图内标题位置批注  
状态：已批准  
选定方向：等宽标题置于主图信息区

## 1. 目标

将鸡尾酒详情页中文酒名放入主图左下的信息区，并置于英文酒名正上方，让中英文名称形成一组完整酒标层级，同时保持：

- 深棕老钱风作为页面基底。
- 香槟金只用于少量点缀。
- 鸡尾酒图片仍是页面主体。
- 394px 移动端与 698px 桌面视口中文字清晰、不重叠、不裁切。
- 其他页面的全局标题样式不受影响。

## 2. 范围

本次只调整 `CocktailDetailPage` 就绪状态下的主图与标题层级：

- 移除品牌标识下方独立的中文标题区。
- 在主图渐暗信息层内增加语义化 `h1`。
- 中文标题紧邻英文名上方，左边缘与英文名、推荐语和参数对齐。

不调整加载、缺失和错误状态标题，不修改图片资源、推荐语、标签、参数、下方内容卡片或 CTA。

## 3. 字体与视觉

中文标题使用系统等宽字体栈，不新增运行时字体资源：

```text
font-family: ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, monospace
font-size: 35px
font-weight: 400
line-height: 1.06（桌面）/ 1.10（移动端）
color: var(--wt-text-main)
letter-spacing: 0
```

标题不使用描边、阴影、渐变或额外装饰线。英文名沿用现有 `eyebrow` 香槟金样式，以较小字号承接中文标题。

## 4. 响应式排版

### 4.1 698px 桌面视口

- 主图沿用 `3 / 2` 比例与 22px 信息层内边距。
- 信息层项目间距为 12px。
- 中文标题保持 35px 单行展示。

### 4.2 394px 移动端

- 主图调整为 `4 / 3` 比例，给新增标题保留纵向空间。
- 信息层内边距收紧为 16px，项目间距为 8px。
- 中文标题仍为 35px，不通过缩小字号牺牲标题层级。
- 长名称允许自然换行，不使用省略号或固定高度裁切。

## 5. 组件落点

- `CocktailDetailPage` 就绪状态不再向 `AppShell` 传入标题。
- 主图内容收敛到 `CocktailHero` 组件，中文名、英文名、推荐语、标签和基础参数保持在同一语义区域。
- `global.css` 使用页面专属的 `.detail-hero-title`，不影响全局 `h1`。

## 6. 验收标准

在 394px 和 698px 两个视口检查：

- 中文名位于主图内部、英文名正上方。
- 中文名与英文名、推荐语、标签和参数左对齐。
- 标题完整显示，无裁切、溢出、重叠或省略号。
- 主图主体仍清晰，标题和信息区有足够对比度。
- 页面上不再出现重复的独立中文标题。
- 加载、缺失、错误状态以及其他页面标题视觉保持原样。
