# WishToday 植物标本抽屉设计规范

## 目标

将 DIY 实验台的“添加材料”底部弹层改造为方案 3“植物标本抽屉”。在不改变搜索、分类、添加和防重复业务逻辑的前提下，让材料选择体验延续项目已确认的深棕皮革书页、香槟金线稿与古老标本册气质。

## 视觉方向

- 弹层使用接近书页内芯的深棕皮革表面，不使用 Warm Ivory、cream、beige、sand 或 off-white 大面积背景。
- 顶部标题改为 `INGREDIENT SPECIMENS / 添加材料`，英文作为小号索引标签，中文作为主标题。
- 弹层顶部保留短拉手，但改为低亮度古铜金，避免塑料感。
- 搜索框为透明深棕底、1px 暗金描边，左侧使用搜索图标；关闭操作使用右上角 `X` 图标按钮。
- 分类使用可换行的紧凑标签。选中态以香槟金描边、轻微金色内衬和高对比文字表示，不使用大面积实色胶囊。
- 材料列表采用标本目录行：左侧标本缩略图，中部材料信息，右侧圆形添加按钮；各行之间使用细金线和微小菱形节点分隔。
- 植物、香草、鲜果优先显示对应标本；其他分类使用同一套精细线刻语言的器具、果实或炼金符号，不使用 emoji 或粗糙 CSS 图形。

## 结构与尺寸

### 移动端（394px / 430px）

- 弹层宽度占满视口，最大高度为 `84dvh`，顶部圆角不超过 `8px`。
- 内容水平内边距 `20px`；列表行最小高度 `88px`。
- 标本缩略图固定为 `56px × 64px`，使用 `object-fit: contain`，低对比度显示，不抢正文层级。
- 材料名称不小于 `16px`，分类与酒精度不小于 `12px`，描述不小于 `13px`，正文行高不低于 `1.55`。
- 分类标签允许换行，单行间距 `6px`，不出现横向页面滚动条。
- 添加按钮为 `34px × 34px` 的圆形图标按钮，使用 `Plus`；已添加状态使用 `Check`，禁用重复添加。
- 底部使用轻量文本动作 `完成添加 →`，与项目书页翻页操作统一，不使用满宽实色按钮。

### 桌面端（698px）

- 弹层居中贴近视口底部，最大宽度 `620px`，最大高度 `78dvh`。
- 标本缩略图为 `64px × 72px`，列表保持单列，便于快速扫描，不改成卡片网格。
- 搜索与分类区域保持固定在弹层顶部，材料列表单独滚动。

## 素材策略

- 视觉依据为 `public/assets/emboss-library/reference-sheets/botanical-page-refined-2x.png`。
- 该文件仍是参考图，不直接裁切后充当每个材料的生产缩略图。
- 首版生产素材从参考方向中整理少量透明单体纹样，并放入 `public/assets/emboss-library/specimens/`；命名使用 `类别-对象-序号.png`。
- 若某材料暂无专属图，使用按分类配置的通用标本图，不生成空白占位块。
- 缩略图统一使用低饱和古铜金、透明背景和细线刻风格；不叠加文字。

## 交互与状态

- 打开弹层后，焦点进入搜索框；`Escape`、关闭按钮、点击遮罩与“完成添加”均可关闭。
- 搜索和分类筛选保持现有逻辑，切换分类时列表回到顶部。
- 点击圆形加号后立即加入当前配方，按钮切换为勾选状态，并显示简短状态反馈。
- 已添加材料不可重复添加，但仍保留在列表中，方便用户确认。
- 加载、空结果和错误状态放在标本列表区域内，使用同一字体与金棕配色，不改变弹层高度。
- 弹层打开时锁定背景页面滚动；弹层自身可滚动。

## 代码边界

- `src/pages/DiyWorkbenchPage.tsx`：调整 `AddIngredientSheet` 的语义结构、图标和状态展示。
- `src/styles/global.css`：增加仅作用于 `.app-shell--leather-book` 内材料弹层的专属样式，避免影响其他底部弹层。
- `src/data/ingredientSpecimens.ts`：集中维护分类到标本素材的映射和回退策略。
- `public/assets/emboss-library/specimens/`：存放透明单体标本素材。
- 不修改 `listIngredients`、Zustand 草稿模型、材料筛选规则和防重复逻辑。

## 可访问性

- 对话框提供标题关联，关闭、添加和已添加按钮均提供可读的 `aria-label`。
- 键盘焦点具有清晰的香槟金轮廓，不能只依赖颜色表达选中或已添加状态。
- 遮罩与弹层正文对比满足当前深色主题的可读性要求。
- 动画只使用短距离上移和透明度变化；系统启用减少动态效果时取消位移动画。

## 验收标准

- 394px、430px 与 698px 视口下无文字重叠、横向溢出或按钮挤压。
- 材料名称、描述和状态在移动端可清晰辨认。
- 方案 3 的标本抽屉气质明确，同时与全站皮革书页背景保持一致。
- 搜索、分类、添加、重复添加拦截、关闭和滚动行为均保持可用。
- `npm test`、`npm run typecheck` 与 `npm run build` 通过。
- 浏览器截图同时覆盖默认列表、搜索结果、已添加状态和空结果状态。

## 非目标

- 不新增材料编辑、收藏或自定义材料能力。
- 不修改 DIY 主页面、预览页或鸡尾酒详情页布局。
- 不引入新的全局色彩体系、字体系统或后端接口。
