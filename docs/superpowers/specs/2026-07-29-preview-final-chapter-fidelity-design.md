# 预览成品页“酒谱终章”高保真复刻设计

## 目标

在不改变 `DiyDraft`、Zustand Store、保存流程和路由行为的前提下，将 `/diy/preview` 继续优化为参考图中的深棕皮革酒谱终章。页面必须保留动态标题、来源、配料、风味标签、备注和保存状态，并以真实页面结构实现，而不是把整张参考图作为静态背景。

视觉基准：

- `C:/Users/zhb/AppData/Local/Temp/codex-clipboard-5956c13c-6c35-46f0-b932-092a46bc49fd.png`
- 基准尺寸：`815x1930`
- 主要验收视口：`394x932`、`698x706`

## 设计方向

采用“真实视觉资产 + 动态 HTML 排版”的高保真实现：

- 继续复用 `/assets/emboss-library/backgrounds/leather-book-page.png` 作为连续书页表面。
- 新增独立的金棕色蜡封资产，复刻不规则蜡边、内圈、月桂、酒杯和“终章”印记。
- 分隔装饰使用项目现有图标库中最接近的菱形图形，并与普通边框线组合，不把复杂装饰硬编码为 CSS 绘画。
- 所有业务文字保持 DOM 文本，保证动态数据、可访问性、响应式换行与交互状态不受影响。
- 不引入 Warm Ivory、cream、beige、sand 或 off-white 大面积背景。

## 页面结构

### 1. 品牌与标题区

- 左上继续显示 WishToday 品牌标记。
- “预览成品”使用居中的香槟金章节眉题，左右加入细线和小型菱形装饰。
- 配方名称成为页面最大标题，使用宋体风格显示字体，允许自然换行，不截断长标题。
- 标题、章节眉题和品牌之间的纵向距离按参考图放大，使首屏更庄重。

### 2. 终章印记区

- 大型蜡封居中显示，移动端宽度约占内容区的 30%–34%，桌面保持视觉重量但设置最大尺寸。
- 蜡封下方显示“酒谱终章”，左右使用短装饰线。
- 来源说明显示为“改造自 {sourceCocktailName}”。
- 蜡封仅用于装饰，使用空替代文本或 `aria-hidden`，不重复朗读“终章”。

### 3. 元信息账簿

- 使用一条带中央装饰节点的横向分隔线与上方内容隔开。
- “英文名 / 基酒 / 材料数”保持三等分。
- 相邻列之间有细金色竖线。
- 标签使用较暗金色，值使用更亮香槟金；英文名允许换行，长文本不得产生横向溢出。

### 4. 配料与调制双栏

- 698px 及宽屏使用比例均衡的双栏，中间保留连续细竖线。
- 394px 仍保留双栏，与参考图一致；通过减小栏间距、控制标题字号和允许步骤自然换行保持可读性。
- 配料区不再使用圆形序号，改为参考图中的名称与用量两端对齐账簿行。
- 每行之间使用低对比度虚线。
- 调制步骤显示真正的步骤文案，而不是重复配料：
  1. 通过 `currentDraft.sourceCocktailId` 查找对应的 `Cocktail`。
  2. 使用该 Cocktail 的 `steps` 数组。
  3. 若来源不存在或 `steps` 为空，回退到当前按配料顺序生成的列表。
- 调制步骤继续使用有序列表语义，长内容自然增高，不设置裁切高度。

### 5. 风味与备注记录

- 从当前左右双栏改为上下两段，复刻参考图的账簿记录方式。
- 每段标题前使用现有图标库中的 `Feather` 图标。
- 风味标签显示为一行或自然换行的“·”分隔文本。
- 备注为空时继续显示“未填写”；非空时显示用户原始文本。
- 两段之间使用低对比度虚线，整个记录区上下使用带中央节点的金色分隔线。

### 6. 状态消息与底部翻页区

- 保存错误或校验消息放在记录区与底部页脚之间，不覆盖操作。
- 底部固定在书页内容末端而非浏览器视口：左侧“返回编辑”、中间页码“IV”、右侧“保存笔记”。
- 按钮视觉继续表现为文字式翻页操作，但实际点击高度不少于 `40px`。
- 保存中状态保留现有图标与“保存中...”文案。
- 三段内容在 394px 和 698px 均不得重叠。

## 数据与组件边界

- `PreviewRecipePage` 负责查找来源 Cocktail、组织回退步骤及渲染动态内容。
- `AppShell` 继续只负责路由外观类、品牌头部和页码，不改变路由判断。
- `BookPageAction` 继续负责返回/前进箭头和翻页交互表现。
- `DiyDraft`、`SavedRecipe`、Store persistence schema、`saveCurrentDraft` 和认证跳转保持不变。
- 不添加新的输入字段，不在 DIY 实验台增加步骤编辑能力。

## 响应式规则

### 394x932

- 正文计算字号不低于 `14px`。
- 书页宽度不得超过视口，不出现横向滚动。
- 配料与步骤保持双栏；步骤允许多行，内容推动书页自然增高。
- 若内容超过单个视口，页面纵向滚动；不得缩小正文来强行塞入一屏。

### 698x706

- 内容区充分利用书页宽度。
- 配料与步骤维持等宽或近似等宽双栏。
- 标题、蜡封和元信息不因宽屏而过度放大。
- 页面自然纵向滚动，底部操作位于文档末端。

## 可访问性与异常处理

- `dl/dt/dd`、`ol/li`、章节 `h2` 语义保持正确。
- 装饰图片和装饰线不进入无障碍名称。
- 返回与保存按钮保留原有键盘可用性、禁用状态和路由行为。
- 来源 Cocktail 查找失败时页面仍完整渲染，并采用配料顺序回退列表。
- 超长标题、材料名、单位、备注和步骤使用自然换行或 `overflow-wrap`，不能扩张页面宽度。
