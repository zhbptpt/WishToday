# 鸡尾酒详情页墨渍底衬设计

## 目标

在不改变鸡尾酒详情页布局、羊皮纸背景、酒杯主图和炼金插画的前提下，为浅色内容区增加半透明深棕墨渍底衬，提高金色文字的可读性，并保持强沉浸古籍手稿风格。

## 视觉方案

- 沿用用户选定的方案 2：暖金色标题与正文搭配深棕色底衬。
- 底衬不是规则卡片，而是独立的真实墨渍纹理图片；边缘具有不对称扩散、纤维渗化、浓淡变化和少量卫星墨点。
- 墨渍主要落在标题说明、三栏参数、风味故事、配料、步骤和调酒师笔记等文字密集区域。
- 雷达图、酒具线稿和大面积羊皮纸仍保持可见，避免墨渍覆盖页面装饰重点。
- 所有墨渍仅作为装饰层，不能影响页面交互和辅助技术读取内容。

## 实现边界

- 仅修改鸡尾酒详情页相关样式和对应布局测试。
- 新增可复用的透明 PNG 墨渍纹理资产，不修改其他五个页面。
- 不新增现代卡片、圆角面板、阴影或新的页面结构。
- 桌面与移动布局均保持现有双栏手稿结构。

## 验收标准

- 浅色羊皮纸上的金色文字明显更易读。
- 墨渍轮廓不规则、半透明、浓淡不均，视觉上像真实墨水渗入纸纤维。
- 墨渍不会遮挡酒杯主体、雷达图关键信息、炼金插画和金属包角。
- 现有鸡尾酒详情页布局测试、全量测试、类型检查和生产构建通过。
