# 其余页面墨渍衬底语言设计

## 目标

将鸡尾酒详情页已确认的半透明深棕墨渍语言延伸到首页、DIY 调酒实验台、添加材料弹层、预览成品页和私人酒谱详情页，在不改变六张古籍背景与现有交互结构的前提下，统一文字对比度和炼金术手稿氛围。

## 选定方案

采用“局部墨渍衬底”：只在标题、摘要、账簿正文和操作附近铺真实不规则墨渍，不做整页深色覆盖，也不引入规则卡片。

- 首页：标题框内使用横向墨迹，推荐卡片文字列使用偏左的宽幅晕染。
- DIY 调酒实验台：题签与简介使用紧凑墨痕，材料区使用纵向墨迹，标签与备注使用较淡的宽幅墨晕。
- 添加材料弹层：标题和搜索区使用宽幅墨迹，材料名称仅使用轻量局部墨痕，保持列表扫描效率。
- 预览成品页：终章标题、元数据账簿、材料与步骤双栏、风味与备注使用不同方向和透明度的墨渍。
- 私人酒谱详情页：标题使用纵向墨迹，摘要使用宽幅墨痕，配料、步骤和备注使用不同变体。

## 视觉与交互约束

- 复用现有三张透明 PNG 墨渍素材，通过尺寸、镜像、旋转、位置和透明度形成不同构图。
- 墨渍必须通过伪元素作为非交互装饰层，使用 `pointer-events: none`，正文和控件始终位于其上方。
- 暖金文字位于深棕墨渍上；未铺墨的浅色羊皮纸区域继续使用深棕或深墨色文字。
- 不遮挡酒杯、炼金插画、植物线稿、金属包角、分页和主要按钮。
- 保持桌面与移动端现有尺寸、双栏关系、滚动区域和交互行为。

## 验收标准

- 五个页面均能辨认出墨渍语言，但落点与构图不重复。
- 文字对比度比原状态更稳定，没有新增长方形卡片感。
- 所有按钮、输入框、列表滚动和弹层关闭行为保持可用。
- 聚焦布局测试、现有单元测试和生产构建通过；逐页视觉检查无 P0-P2 问题。
