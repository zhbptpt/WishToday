# 首页每日推荐区一比一复刻设计

## 目标

以用户提供的 `1184 × 1328` 参考图为唯一视觉真值，重新实现首页中的“每日推荐标题＋Old Fashioned 图文区”。复刻范围不包含首页顶部标题墨渍模块，也不改变其他页面。

参考图的源栅格为 `1184 × 1328`；视觉对照使用相同宽高比，并将源图坐标归一化后比较，不把设备像素比误当成 CSS 布局宽度。标准画布下需要匹配参考图的总体比例、留白、文字层级、酒杯尺寸与位置、照片洗印范围以及轮播按钮位置。较窄屏幕按相同比例响应式缩放，不通过裁切酒杯换取布局空间。

## 选定方案

采用结构化精准复刻：真实酒杯照片与专属柔边洗印遮罩组成图像列，标题、英文名、分隔线、说明和风味标签继续使用可访问的 HTML 文本，轮播按钮保留真实交互。

不采用整块图片平铺，因为它会使文字不可响应、不可选择，并破坏轮播内容切换。不继续仅靠现有通用遮罩试调，因为现有遮罩的边缘与参考图的宽幅柔和洗印效果不同，无法稳定达到视觉一致。

## 版式

### 标准画布

- 视觉基准源图为 `1184 × 1328`；若浏览器使用 `2x` 设备像素比，对应 CSS 视口为 `592 × 664`。
- 推荐标题组位于画布左上区域，英文眉题在上、中文标题在下。
- 左右轮播按钮与标题组处于同一水平区域，并固定在右侧。
- 标题区与酒款图文区之间保留参考图中的大段羊皮纸留白，不增加边框、卡片底色或分隔容器。
- 酒款图文区采用左右两列自然交叠：文字列约占可用宽度的 `38%`，图像列约占 `48%`。
- 酒杯位于右侧偏下，杯口、橙皮、杯身和杯底全部可见；酒杯视觉高度约为图文区高度的 `78%`。

标准源图上的主要对齐锚点如下，响应式布局按画布宽高等比例换算：

- 推荐标题组左边约为 `190px`，英文眉题顶部约为 `278px`。
- 两个轮播按钮中心约为 `(916px, 332px)` 和 `(1034px, 332px)`。
- 酒名文字列左边约为 `225px`，中文酒名顶部约为 `634px`。
- 酒杯主体约落在 `610–985px × 620–1115px` 范围内。
- 柔边洗印范围约落在 `555–1035px × 565–1185px` 范围内。

### 文字列

- 中文酒名使用深棕宋体风格，字号与参考图一致，保持单行。
- 英文酒名紧随中文酒名下方，使用衬线体。
- 英文名下使用参考图中的细线装饰，不使用当前通栏实体分隔线。
- 描述固定为两行视觉节奏，行距和字距按照参考图收敛。
- 风味标签位于底部虚线之下，两个标签之间使用短竖线分隔；不保留当前上下双实线框。

### 图像列

- 使用现有 `public/mock/cocktails/old-fashioned.png` 作为唯一酒杯照片源，禁止生成或替换酒杯主体。
- 为 Old Fashioned 增加专属透明栅格遮罩，形成参考图中的横向暖褐柔边矩形洗印。
- 遮罩中心区域保留原图细节，四周逐渐淡化到羊皮纸；不使用椭圆裁切，不让羽化边缘穿过酒杯。
- 图像保持暖褐古籍洗印色，但酒液、橙皮、冰块切面和杯底折射要明显可辨。
- 照片背景允许保留适量桌面阴影，不能出现明显的原照片硬边。

## 响应式规则

- `1184 × 1328` 源栅格或其等比例 CSS 视口为像素级对照基准；不得用非等比例拉伸制造匹配。
- 桌面及平板宽度按容器比例缩放标题、留白、文字列和图像列。
- 小于 `621px` 时仍保持左右图文关系；允许统一缩小字号和酒杯，但不切换成上下堆叠，也不裁切酒杯主体。
- 所有断点保留轮播按钮可点击区域，并避免图像覆盖左侧文本。

## 交互与数据

- 轮播上一杯、下一杯和分页行为保持现状。
- 点击推荐区继续进入当前酒款详情页。
- Old Fashioned 使用专属几何和遮罩；其他酒款沿用同一文字版式，并使用各自图像类进行必要的主体定位，不能因本次改动失去完整主体。
- 不修改鸡尾酒数据结构、路由或接口。

## 实施边界

- 主要改动限制在 `src/styles/global.css`、首页推荐区必要的类名以及对应测试。
- 新增的洗印遮罩存放在 `public/assets/ink-wash/`。
- 不修改六张页面背景，不修改首页顶部墨渍标题模块，不修改详情页、DIY、材料弹层、预览页或私人酒谱页面。

## 验收标准

- 在 `1184 × 1328` 源栅格对应的同宽高比、同滚动状态截图中，推荐标题、按钮、图文区边界、文字层级和酒杯占比与参考图一致；主要锚点偏差不超过画布宽度或高度的 `3%`。
- 酒杯完整显示，杯口、橙皮、杯身、杯底均无裁缺。
- 酒杯主体细节清楚，照片背景由中心向四周柔和淡出，没有椭圆边缘或硬矩形边缘。
- 左侧文本没有被图像覆盖，描述和风味标签排版与参考图一致。
- 在 `678 × 706` 和 `430px` 宽度下保持完整酒杯和可读文字。
- 轮播、分页和点击进入详情页行为正常。
- 聚焦测试、生产构建和 `git diff --check` 通过。
- 最终 `design-qa.md` 使用参考图与实页截图进行同视口对照，不存在 P0、P1 或 P2 差异，并记录 `final result: passed`。
