# 鸡尾酒详情页棕色墨渍统一设计

## 目标

将鸡尾酒详情页当前偏黑灰的墨渍恢复为与首页、DIY、添加材料、预览和私人酒谱页面一致的深棕至浅棕自然过渡，同时保留现有古籍手稿氛围与文字可读性。

## 已确认原因

详情页与其他页面复用了同一套透明 PNG 墨渍素材。素材本身已经包含深棕核心、暖棕中间层和浅棕羽化边缘；详情页额外应用的低饱和度 `filter` 把原始棕色色阶压成了黑灰色。其他页面没有应用这组灰化滤镜。

## 采用方案

采用方案 1：移除鸡尾酒详情页墨渍层上的灰化滤镜，直接呈现原始棕色素材；如实际页面出现局部过深，仅微调对应墨渍层的 `opacity`，不重新染色、不生成重复素材。

## 修改范围

- 调整 `src/styles/global.css` 中 `.app-shell--cocktail-detail-book` 下的墨渍伪元素。
- 覆盖顶部标题墨渍、信息条墨渍和内容章节墨渍，使所有区域采用统一暖棕色阶。
- 保留现有墨渍图片、形状、尺寸、位置、旋转、镜像与层级。
- 保留详情页背景、酒图、排版、金色文字、深色正文和交互行为。
- 不修改其他页面的墨渍样式或全局素材文件。

## 视觉成功标准

- 墨渍中心呈深咖啡棕，不再呈中性黑灰。
- 墨渍边缘可见浅棕和纸张融合的羽化过渡。
- 顶部、信息条和下方章节的色温一致。
- 金色浅色文字在深棕墨渍上保持清晰，不出现对比度倒退。
- 手机与较宽视口均不出现布局、裁切或层级变化。

## 验证策略

1. 先新增样式回归断言，要求详情页墨渍不再包含旧的低饱和灰化滤镜，并运行得到预期失败。
2. 最小化修改详情页滤镜规则，再运行相关布局测试确认通过。
3. 在 `/cocktails/old-fashioned` 捕获修改前后同视口截图，与其他页面棕色墨渍基调并排核对。
4. 检查返回按钮、DIY 调酒入口等主要交互及浏览器控制台。
5. 运行相关测试、生产构建与 `git diff --check`。

## 非目标

- 不重新设计墨渍形状或新增墨渍区域。
- 不改变详情页内容结构、文案或数据。
- 不重新生成图片素材。
- 不对其他页面做额外视觉优化。
