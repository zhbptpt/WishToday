# 首页鸡尾酒暖色古籍洗印设计

## 目标

让首页每日推荐中的鸡尾酒照片在保留古籍洗印质感的同时，呈现稳定的暖色调，重点恢复酒液的琥珀、焦糖与橙棕色，使其不再显得灰冷或接近黑白照片。

## 选定方向

采用“琥珀焦糖洗印”。背景洗印层使用偏深的焦糖褐，主体层使用更温和的琥珀暖色，并保持玻璃、冰块、橙皮和酒液高光可辨。

## 视觉规则

- 只调整 `.home-feature-photo--wash` 与 `.home-feature-photo--subject` 的滤镜参数。
- 背景洗印层保持柔和、低对比，并继续使用 `multiply` 混合模式。
- 主体层提高暖色饱和度，加入轻微负向色相偏移，避免灰黑和冷黄。
- 不新增黑色墨块，不使用纯橙色覆盖层，不牺牲透明玻璃与冰块细节。
- 不改变图片尺寸、位置、`object-fit`、透明度、混合模式、遮罩资源或遮罩几何。

## 验收标准

- Old Fashioned 酒液呈琥珀焦糖暖色，而不是灰黑或黑白。
- 酒杯完整显示，杯口、橙皮、杯身、冰块与杯底不被裁切。
- 图片背景仍从主体向羊皮纸自然淡出，边缘维持不规则矩形洗印效果。
- 左侧文字、分页控件与推荐区版式不发生位移。
- 首页布局聚焦测试、完整测试、生产构建和 `git diff --check` 通过。
