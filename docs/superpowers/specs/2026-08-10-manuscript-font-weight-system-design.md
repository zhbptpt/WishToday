# 古籍手稿字重系统设计

## 目标

在不改变现有暖褐羊皮纸、深浅棕墨渍、图片构图和页面布局的前提下，提高七个核心页面的中文阅读清晰度，并让标题、正文、数值与操作形成稳定层级。

覆盖页面：首页、鸡尾酒详情页、DIY 调酒实验台、添加材料弹层、预览成品页、私人酒谱详情页、私人笔记本。

## 选定方案

采用“全局语义字重 token + 页面局部映射”。不引入外部 WebFont，不逐页重复一套互相覆盖的声明，也不对所有文字统一加粗。

## 字重层级

- 品牌字标：800
- 主标题与章节标题：600
- 正文、步骤、输入、说明、元信息：500
- 数值、配方用量与强调信息：600
- 按钮、选中标签与关键操作：700

## 字体渲染策略

保留现有字体家族和古籍视觉气质。允许浏览器在缺少对应中文字体字重时合成需要的粗体，避免 `font-synthesis: none` 导致 500/600/700 在部分 Windows 中文字体上退化为相同的细字形。

通过 CSS 自定义属性集中定义语义字重，并在全局基础规则后追加一个单一的字重系统区块。页面特有选择器只负责将现有组件映射到语义层级，不改颜色、字号、行高、间距或背景。

## 验收标准

- 七个页面标题明显强于正文，但不呈现现代海报式粗黑感。
- 正文、步骤、输入和元信息在羊皮纸与墨渍区域均可快速辨认。
- 数值与用量比周边正文更醒目。
- 按钮与选中标签具备最强操作层级。
- 品牌字标继续保持最高辨识度。
- 桌面与窄屏布局、墨渍、背景、照片蒙版均无变化。
- 自动测试、类型检查和生产构建通过，并逐页进行浏览器截图验证。
